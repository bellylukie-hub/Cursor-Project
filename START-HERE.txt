This ZIP contains EVERY module developed to date — merged into one deployable app.

QUICK START (Docker — recommended)
----------------------------------
1. Install Docker and start it
2. In this folder:

   cp .env.example .env
   Edit .env — set JWT_SECRET (32+ random characters)
   RUN_SEED=true for first install only

   docker compose down
   docker compose up -d --build

3. Open: http://localhost:3001
   Login: super_admin / ChangeMe123!

4. After first login: RUN_SEED=false in .env → docker compose up -d --build

IMPORTANT — AFTER ANY UPDATE
----------------------------
Always rebuild Docker or you will NOT see new features:

   docker compose down
   docker compose up -d --build
