This ZIP is the COMPLETE production web application — all FMS features included.

QUICK START (Docker — recommended on Windows, Linux, macOS)
------------------------------------------------------------
1. Install Docker Desktop (Windows/Mac) or Docker Engine (Linux) and start it
2. Open a terminal in this folder:

   cp .env.example .env          (Windows: copy .env.example .env)
   Edit .env — set JWT_SECRET (required, 32+ random characters)
   RUN_SEED=true for first install only

   docker compose up -d --build

3. Open: http://localhost:3001
   Login: super_admin / ChangeMe123!

4. After first login, edit .env → RUN_SEED=false → docker compose up -d

DEPLOY ON YOUR DOMAIN (worldwide HTTPS)
---------------------------------------
1. Run on a cloud VPS (Ubuntu + Docker) using steps above
2. Point your domain A record to the server IP
3. Put Caddy or nginx in front for HTTPS (port 443 → localhost:3001)
4. Set CORS_ORIGIN=https://your-domain.com in .env

See: docs/images/domain-deployment.svg
