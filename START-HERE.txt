This ZIP is the COMPLETE production web application — all FMS features included.

QUICK START (Docker — recommended on Windows, Linux, macOS)
------------------------------------------------------------
1. Install Docker Desktop (Windows/Mac) or Docker Engine (Linux) and start it
2. Open a terminal in this folder:

   cp .env.example .env          (Windows: copy .env.example .env)
   Edit .env — set JWT_SECRET (required, 32+ random characters)
   RUN_SEED=true for first install only

   docker compose up -d --build

3. Open: http://localhost:3001
   Login: super_admin / ChangeMe123!

4. After first login, edit .env → RUN_SEED=false → docker compose up -d

INSTALL OPTIONS
---------------
  Docker          — easiest; works on Windows, Linux, macOS
  WAMP + Docker   — Windows: run app in Docker; optional Apache proxy on :80
  Linux manual    — ./install-linux.sh  then  cd backend && npm start
  PM2 (24/7)      — pm2 start ecosystem.config.cjs  (see PRODUCTION.md)
  XAMPP / LAMP    — reverse proxy to port 3001 only (see docs/INSTALLATION.md)

WHAT IS INCLUDED (FULL WEB APP — v2.0.0)
-----------------------------------------
  OPERATIONS
  - JWT login and RBAC (users, roles, module permissions, area assignments)
  - NB / SB / Border / POD / Position Live operations tables
  - Live column manager, KPI colours, upload templates
  - Turnarounds, runner fees, customizable reports

  FREIGHT MANAGEMENT (FMS)
  - Client Orders — full FMS order form (route, borders, cargo, container/OOG)
  - Clients — dedicated client register (CRM)
  - Route Catalog — countries, stations, loading/offloading points, route templates
  - Trip Scheduler — assign fleet sets to client orders with auto-fill dropdown
  - Fleet Registry — trucks, trailers, drivers, fleet sets, superlink pairing
  - Full FMS vehicle register (~87 columns)

  ADMIN
  - Users, roles, KPI settings, audit logs, themes, upload templates
  - Freight & FMS Settings — configure trip scheduler, orders, routes, fleet policies
  - Fleet — Same Truck for SB turnaround policy

  SUPPORT
  - Help assistant (chatbot) with guides for all menus and FMS workflows
  - Process guide in comment modal, driver registry, communication matrix
  - Docker + PM2 deployment files, sample CSV templates in samples/
