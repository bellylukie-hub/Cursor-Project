  TruckControl — PRODUCTION PACKAGE  (v1.2.0-production)
================================================================================

This ZIP is the full production web application with login, database, reports,
themes, position sync, turnarounds, and complete documentation.

QUICK START (Docker — recommended on Windows, Linux, macOS)
------------------------------------------------------------
1. Install Docker Desktop (Windows/Mac) or Docker Engine (Linux) and start it
2. Open a terminal in this folder:

   cp .env.example .env          (Windows: copy .env.example .env)
   Edit .env — set JWT_SECRET (required, 32+ random characters)
   RUN_SEED=true for first install only

   docker compose up -d --build

3. Open: http://localhost:3001
   Login: super_admin / ChangeMe123!

4. After first login, edit .env → RUN_SEED=false → docker compose up -d

INSTALL OPTIONS
---------------
  Docker          — easiest; works on Windows, Linux, macOS
  WAMP + Docker   — Windows: run app in Docker; optional Apache proxy on :80
  Linux manual    — ./install-linux.sh  then  cd backend && npm start
  PM2 (24/7)      — pm2 start ecosystem.config.cjs  (see PRODUCTION.md)
  XAMPP / LAMP    — reverse proxy to port 3001 only (see docs/INSTALLATION.md)

WHAT IS INCLUDED
----------------
  - JWT login and RBAC (users, roles, module permissions)
  - NB / SB / Border / POD / Position Live operations tables
  - Position upload sync to NB/SB (matched by trip + truck)
  - Customizable per-menu and cross-menu reports
  - Turnarounds list with filters and KPI summary
  - Sidebar live badges and notification bell
  - Themes, process guide, help assistant
  - Driver registry, communication matrix, runner fees
  - Admin: users, roles, KPI settings, audit logs, upload templates
  - Docker + PM2 deployment files
  - Sample CSV templates in samples/
